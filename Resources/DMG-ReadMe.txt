HalfShell — 읽어 주세요 / Read Me
================================================================

[한국어]

설치
----
HalfShell.app 을 옆의 Applications 폴더로 드래그한 뒤 실행하세요.
창은 뜨지 않고 메뉴 막대 오른쪽에 노트북 아이콘이 생깁니다.
아이콘을 눌러 "외장 연결 시 내장 디스플레이 자동 끄기"를 켜면 됩니다.

설치 직후 꼭 해 두세요 — 화면 복구 단축키
------------------------------------------
만에 하나 화면이 켜지지 않으면 마우스도 터미널도 쓸 수 없습니다.
그때 손만으로 빠져나올 수 있게 미리 열어 두는 설정입니다.

  시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → HalfShell 켜기

  ※ 이름이 같은 "시스템 설정 → 손쉬운 사용"은 다른 곳입니다.

허용하면 Command 키만 4초 안에 5번 누르는 것으로 내장 화면이 켜집니다.
권한이 없어도 자동 끄기와 자동 복구는 정상 동작합니다.

화면이 켜지지 않으면
--------------------
위에서부터 시도하세요.
  1. Command 키만 4초 안에 5번 누르기 (위 권한을 허용한 경우)
  2. 외장 디스플레이 케이블을 뺐다 다시 꽂기 — 권한과 무관하게 됩니다
  3. 전원 버튼을 길게 눌러 강제 재시작 — 저장하지 않은 작업은 사라집니다

Lunar / BetterDisplay 를 함께 쓴다면
------------------------------------
내장 디스플레이를 끄는 기능만 겹칩니다(Lunar 의 BlackOut,
BetterDisplay 의 disconnect). 그 기능만 한쪽에서 꺼 두세요. 둘 다 켜 두면
서로 되돌리며 화면이 깜빡입니다. 나머지 기능은 함께 써도 됩니다.

업데이트
--------
새 버전이 나오면 메뉴에 "새 버전 받기…"가 나타납니다.
메뉴에서 HalfShell 을 종료한 뒤 새 앱으로 바꿔 넣으세요.
손쉬운 사용 권한은 업데이트해도 그대로 유지됩니다.

지원 환경
---------
- macOS 13 이상, 내장 디스플레이가 있는 Mac (MacBook)
- Apple Silicon 에서 검증했습니다. Intel Mac 은 실행되지만 검증하지 못했습니다.
- Mac mini / Studio / Pro 는 내장 디스플레이가 없어 기능이 잠깁니다.
- macOS 가 공개하지 않은 기능을 씁니다. 큰 macOS 업데이트 뒤에는
  동작을 한 번 확인해 주세요.

[English]

Install
-------
Drag HalfShell.app into the Applications folder next to it and open it.
No window appears; a laptop icon shows up on the right side of the menu bar.
Click it and turn on "Turn Off Built-in When External Connected".

Do this right after installing — screen recovery shortcut
---------------------------------------------------------
If the screen ever stays black, you can't use the mouse or Terminal.
This setting keeps a way out that works with the keyboard alone.

  System Settings → Privacy & Security → Accessibility → turn on HalfShell

  Note: "System Settings → Accessibility" is a different place.

Once allowed, tapping only the Command key 5 times within 4 seconds turns the
built-in display back on. Automatic turn-off and recovery work without it.

If the screen doesn't come back
-------------------------------
Try these in order.
  1. Tap only the Command key 5 times within 4 seconds (if allowed above)
  2. Unplug the external display cable and plug it back in — always works
  3. Hold the power button to force a restart — unsaved work is lost

Using Lunar or BetterDisplay too
--------------------------------
Only the feature that turns off the built-in display overlaps (Lunar's
BlackOut, BetterDisplay's disconnect). Turn that one feature off in one of
the apps. With both on, they keep undoing each other and the screen flickers.
Everything else can be used together.

Updates
-------
When a new version is out, "Get Version …" appears in the menu.
Quit HalfShell from the menu, then replace the app with the new one.
The Accessibility permission stays across updates.

Requirements
------------
- macOS 13 or later, a Mac with a built-in display (MacBook)
- Verified on Apple Silicon. Runs on Intel Macs but has not been verified.
- Mac mini / Studio / Pro have no built-in display, so features are locked.
- Uses features macOS does not make public. After a major macOS update,
  please check that it still works.
